Quick start

  1. Create CoinDCX API keys — CoinDCX → Profile → API Dashboard. Enable balance + trading. Prefer no IP binding unless you allowlist connector hosts.
  2. Get a connector review key — ask ashutosh.db.mail@gmail.com for x-connector-key (Muse ↔ this server).
  3. Connect the user — POST /account/connect with { "api_key", "api_secret" }. Store the returned connection_token.
  4. Call voice APIs — send X-COINDCX-CONNECTION + x-connector-key on every request.

Authentication

Two layers. CoinDCX has no OAuth for trading — this connector uses API keys only.

HeaderWhoPurpose
x-connector-key Muse / reviewer Shared secret proving the caller is allowed to use this deployment
X-COINDCX-CONNECTION Per user Encrypted token from POST /account/connect (preferred)
X-COINDCX-API-KEY + X-COINDCX-API-SECRET Debug only Raw keys instead of the connection token
Keys are sealed per user and never shared across accounts. The connector does not custody INR or crypto.

Safe voice trading

Prefer quote → confirm so Muse can speak fees before any live order.

  1. POST /orders/quote with side, coin, and amount_inr (or quantity / all for sells).
  2. Read spoken_summary + fee fields aloud. Keep quote_id.
  3. On user confirm: POST /orders/confirm with { "quote_id" }. Server waits for fill (~12s).

Amounts are INR-native (amount_inr), not USD.

Examples

Health

curl -s https://coindcx-muse-connector.vercel.app/health

Connect

curl -s -X POST https://coindcx-muse-connector.vercel.app/account/connect \
  -H "content-type: application/json" \
  -H "x-connector-key: YOUR_CONNECTOR_KEY" \
  -d '{"api_key":"YOUR_COINDCX_KEY","api_secret":"YOUR_COINDCX_SECRET"}'

Portfolio

curl -s https://coindcx-muse-connector.vercel.app/account/portfolio \
  -H "x-connector-key: YOUR_CONNECTOR_KEY" \
  -H "X-COINDCX-CONNECTION: YOUR_CONNECTION_TOKEN"

Quote buy ₹200 USDT

curl -s -X POST https://coindcx-muse-connector.vercel.app/orders/quote \
  -H "content-type: application/json" \
  -H "x-connector-key: YOUR_CONNECTOR_KEY" \
  -H "X-COINDCX-CONNECTION: YOUR_CONNECTION_TOKEN" \
  -d '{"side":"buy","coin":"USDT","amount_inr":200}'

Limits & access requirements

  • Account: KYC-verified CoinDCX India account with API key creation.
  • Rate limit: ~200 requests / 15 minutes per IP on this connector; CoinDCX upstream limits also apply.
  • Live orders: enabled when ALLOW_LIVE_ORDERS=true on the deployment.
  • Deposits / cards: not supported — users fund CoinDCX themselves; connector only trades existing balance.
  • Support: ashutosh.db.mail@gmail.com
